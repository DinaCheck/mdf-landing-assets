# MDF — пакет для GitHub Pages без TT Travels

**Публичная публикация**: ничего автоматически не загружено. Загружать архив можно только в согласованный публичный репозиторий. Его содержимое и сайт GitHub Pages будут доступны всем.

## Состав

- `index.html` — локальный/Pages предпросмотр с шапкой Figma.
- `bitrix24-paste-template.html` — HTML для блока конструктора с уже скрытой внутренней шапкой.
- `assets/figma/` — оригинальные PNG и SVG.
- `assets/fonts/Montserrat.ttf` — единственный шрифт. **TT Travels отсутствует**, в CSS заменён на Montserrat.

## Размещение

1. Создать отдельный публичный репозиторий GitHub, например `mdf-landing-assets`, если это согласовано.
2. Распаковать архив и загрузить `index.html`, `bitrix24-paste-template.html` и папку `assets` с сохранением структуры.
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. Открыть выданный URL Pages: должны загрузиться все иллюстрации; проверить на телефоне.
5. В `bitrix24-paste-template.html` заменить `__ASSET_BASE_URL__` на базовый URL Pages *без* завершающего слеша (например `https://username.github.io/mdf-landing-assets`).
6. Проверить прямой адрес одного файла `.../assets/figma/MetabollsSphere1.png`, затем вставлять HTML в пустой блок копии Bitrix24.

## Внимание перед публикацией MDF

- Оригинальная форма в исходном макете — только визуал без отправки. Нужна форма от команды Инны Озерной.
- Кнопка «Скачать программу» пока не связана с официальным документом.
- Окна пяти форматов используют текст условий из присланного рабочего HTML. Требуется финальное юридическое согласование.
- Не использовать старую форму inline/3534/uasuxk.
